# fabric-mod-java-template

[![Copier](https://img.shields.io/endpoint?url=https://raw.githubusercontent.com/copier-org/copier/master/img/badge/badge-grayscale-inverted-border-orange.json)](https://github.com/copier-org/copier)

An opinionated project template for a Fabric mod written in Java.

## Usage

To generate a project via this template:

1. Install [`copier`](https://copier.readthedocs.io/en/stable/#installation) via one of the provided tools
2. `copier copy gh:olehrstm/fabric-mod-java-template <destination>`
3. Answer the prompted questions
